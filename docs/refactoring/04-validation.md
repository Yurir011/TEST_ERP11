### 테스트를 통해 확인된 사항
- 직전에 개발한 **부분 수금/지급 기능이 의도대로 동작**한다(부분 결제 → 잔액 감소, 최종 결제 시 완납, 삭제 시 복원, 완납 건의 분할 결제 삭제 차단).
- 기존 동작을 고정하는 테스트라서 **코드 수정 없이 전부 통과**했다. 실패가 없었으므로 현재까지 발견된 신규 버그는 없다.

### 실행하지 못한 / 아직 없는 검증
- **프론트엔드 자동 테스트**: 러너 미도입. 화면 동작은 수동 점검(`docs/테스트_절차서.md`)에 의존한다.
- **브라우저 기반 화면 검증**: 이 환경에서는 실행하지 않았다.
- **아직 테스트가 없는 영역**: 품의서·증명서·프로젝트 문서의 결재 흐름, 팝빌·홈택스·OCR 연동, PDF·엑셀 생성 결과, 정기이체 생성. 해당 모듈을 P3에서 손대기 전에 테스트를 먼저 추가한다.
- 테스트는 PostgreSQL 전용 타입(ARRAY, enum)을 쓰기 때문에 `erp_test`(PostgreSQL)가 있어야 실행된다.
