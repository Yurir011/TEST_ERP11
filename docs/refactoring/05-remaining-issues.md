## 4. 기능 개발 항목 (리팩토링 범위 밖)

- R4: 외화(달러·엔) 거래 — 매입매출·입출금은 원화만 지원한다. 문서(견적서 등)만 통화를 가진다.
- NFC 인증: 코드가 아직 없다. 출퇴근 서비스가 인증 수단에 의존하지 않도록 `clock_in(user_id, source)` 형태의 경계와 어댑터 모듈(`services/auth_devices/`)을 두는 설계를 제안한다(02-plan.md 3장).

## 5. 자동으로 검증하지 못한 영역

- **자동 테스트가 없는 백엔드**: 팝빌·홈택스·OCR 연동, PDF·엑셀 생성 결과, 정기 이체 생성, 품의서 결재, 이미지 업로드.
- **프론트엔드 화면 동작**: 컴포넌트 테스트가 없어 이번 리팩토링의 화면 변경(페이지 분해·승인 훅)은 아래 **수동 점검 체크리스트**로 확인해야 한다.

### 수동 점검 체크리스트 (한 번씩 눌러 보기)

1. **전자결재**: 연차·증명서 승인·반려, 품의서 승인(확인창 문구)·반려, 견적서 승인, 삭제 요청 문서 승인(삭제 확인 문구), 대시보드 업무 알림 모달에서의 승인
2. **입출금관리**: 상단 카드(거래처 칸 클릭=상세, 처리 버튼=처리창), 전체/이번달/지난달 금액, 카드 결제예정 상세, 카드 탭 요약 상자 필터, 표의 행 클릭·영수증·인쇄·엑셀·삭제, 부분 수금·지급 처리와 "(일부)" 표시
3. **문서관리**: 전체 탭에서 품의서와 문서 혼합 목록, 표의 저장·엑셀·출력·메일·삭제 아이콘, "재요청" 버튼, 내 결재함 상자, 세금계산서 통계 카드 필터·검색
4. **프로젝트 상세**: 진행상황 항목 추가·삭제·진행율 → 종합 진행률 자동 반영, 수동 선택, 일정 저장, 주차 그리드, 견적서·거래명세서 세트 다운로드
5. **문서 파일**: 견적서·세금계산서를 하나 만들어 승인한 뒤 PDF 합계가 화면과 같은지(부가세 사사오입), 팝빌 발행, 이미지 업로드
6. **날짜**: 오전 9시 전에 입출금·매입매출 등록 화면의 기본 날짜가 오늘인지
