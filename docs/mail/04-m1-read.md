## 만든 것
| 영역 | 내용 |
|---|---|
| **계정 등록** | 사이드바 **메일**(앱에서만 보임) → 이메일·비밀번호 입력 → **접속을 확인한 뒤에만 저장**. 서버 주소·포트는 기본값이 다음스마트워크(IMAP `imap.daum.net:993`, SMTP `smtp.daum.net:465`, 암호화 접속)이고 [서버 설정 보기]에서 바꿀 수 있다. 비밀번호 칸에 눈 버튼 |
| **비밀번호 보관** | Windows 암호화 저장소(`safeStorage`)로 암호화해 이 PC 의 `userData/mail/account.json` 에만 저장. 서버·화면·로그에 나가지 않는다. 암호화를 쓸 수 없는 PC 에서는 저장을 거부(평문 저장 없음) |
| **로컬 저장소** | 이 PC 의 SQLite(`userData/mail/mail.db`). 목록(헤더)은 동기화 때, **본문은 메일을 열 때** 내려받아 저장 |
| **동기화** | 폴더 목록, 최근 **90일** 메일의 헤더, 서버에서 지운 메일 반영(오래돼서 기간 밖이 된 메일은 지우지 않음), 읽음·별표 표시 반영, UIDVALIDITY 가 바뀌면 그 폴더 사본을 버리고 다시 받음. 서버가 IDLE 을 지원하지 않아 **새 메일은 [새로고침] 또는 메일 화면을 열 때** 가져온다(자동 주기 확인은 M3) |
| **메일 창** | ERP 사이드바의 **[메일] 버튼**(앱에서만 보임)을 누르면 **별도 창**이 열린다. 이미 열려 있으면 그 창을 앞으로 가져온다. 메인 창은 그대로 ERP 화면. 메일 창에는 ERP 사이드바가 없고 메일 화면만 크게 보인다(다음 메일 화면 모양을 참고해 구성) |
| **화면 구성** | 왼쪽: 내 이름·메일 주소·계정 설정(톱니), 빠른 조건(**안읽음·중요·첨부**), 메일쓰기·내게쓰기(아직 비활성), 폴더(**전체메일**·받은메일함·내게쓴메일함·보낸메일함·임시보관함…, 안 읽은 수). 오른쪽: 현재 폴더 이름, 도구줄(전체 선택, 삭제·스팸신고·전달·이동은 아직 비활성, **읽음 표시**, 선택 수 `0 / 3`, **새로고침**, **검색**), 한 줄씩 목록(체크·**별표**·읽음 아이콘·보낸 사람·제목·첨부·날짜), **쪽 번호**와 보기 설정(20/50/100개씩) |
| **본문 보기** | HTML 메일은 정리된 내용을 **격리된 틀(sandbox iframe)** 에서 표시, 텍스트 메일은 그대로. **외부 이미지는 기본 차단**, 안내줄의 [이미지 보기]로 허용. 링크는 새 창 → 앱이 기본 브라우저로 연다 |
| **첨부** | 이름·크기 표시, **[열기]**(임시 폴더에 풀어서 열기, `.exe`/`.bat`/`.ps1`/`.lnk` 같은 실행 파일은 한 번 더 확인), **[저장]**(저장 위치를 사용자가 고름) |
| **읽음 표시** | 메일을 열면 읽음으로 바뀌고 서버에도 반영(서버에 못 알려도 다음 동기화에서 서버 값으로 맞춤) |
| 앱 연결 | `window.benchClient.mail.*` (서버 화면에서만 호출 가능, 안내 화면·PDF 새 창에서는 거절). 메일 창에는 같은 앱 통로가 주어진다 |

## 보안 장치
- **HTML 정리**(앱 쪽, `sanitize-html`): script·iframe·object·embed·form·style·svg 제거, `on*` 이벤트 속성 제거, `javascript:`/`data:` 링크 제거, 스타일의 `url()`·`expression()` 제거, 원격 이미지 제거(허용 전), 처리 못 한 `cid:` 이미지 제거, 모든 링크에 `target=_blank` `rel=noopener noreferrer` 와 실제 주소 `title`.
- **화면 쪽 한 번 더**(iframe): `sandbox` 에 스크립트·같은 출처 권한 없음(팝업만 허용), CSP `default-src 'none'; img-src data:`(이미지 보기를 눌러야 https 허용), `form-action 'none'`, `referrerpolicy=no-referrer`.
- **입력 검사**: 메일 번호·폴더 이름·첨부 번호·페이지 값 형식 검사, 계정 입력(이메일·호스트·포트·줄바꿈) 검사.
- **TLS 인증서 검증을 켠 채로 접속**한다(예외 코드 없음). 서버 인증서가 믿을 수 없으면 연결을 막고 안내.
- **오류 문구**에 서버 응답 원문이나 비밀번호를 넣지 않는다.
- 첨부 저장 이름은 경로·금지 문자 제거.

## 미확인 (직접 확인 필요)
1. **실제 다음스마트워크 로그인**: 일반 비밀번호로 되는지, 외부 프로그램(IMAP/SMTP) 사용 설정이 필요한지, 2단계 인증 계정은 앱 비밀번호가 필요한지. (설정 화면이 만들어졌으니 직접 입력해서 확인해 주세요. 실패하면 화면에 이유가 나옵니다.)
2. 실제 계정의 **폴더 이름**(보낸편지함·휴지통 등 한글 폴더명)이 올바르게 보이는지. 서버가 폴더 용도를 알려 주지 않아 이름으로 짐작하는 부분이 있다(받은편지함은 확실).
3. 실제 메일(광고·뉴스레터 등 복잡한 HTML, 한글 인코딩이 특이한 오래된 메일)이 보기 좋게 나오는지. 보안을 위해 일부 서식(`<style>` 태그, 일부 CSS)은 일부러 제거한다.
4. **첨부 [열기]·[저장]** 의 Windows 대화상자와 위험 파일 확인 창(자동 시험은 대화상자를 띄우지 않는다), **링크를 눌렀을 때 기본 브라우저가 열리는지**.
5. 큰 사서함(수천 통)의 첫 동기화 시간.
6. 설치 파일(`.exe`)은 이번에 새로 만들지 않았다(`dist:dir` 로 묶은 앱까지 확인). 배포하려면 버전을 올려 `npm run dist`.
7. 다크 테마·작은 창에서의 모양.

## 직접 확인 목록
1. 앱 실행 → 사이드바의 **[메일] 버튼** → 새 창이 열리는가(다시 눌러도 하나만 열리는가) → 이메일·비밀번호 입력 → 등록. (틀린 비밀번호로도 한 번 해서 안내 문구 확인)
2. 받은편지함에 **내 실제 메일**이 한글 제목과 함께 보이는가, 안 읽은 수가 맞는가
3. 메일을 열었을 때 본문·보낸 사람·날짜가 맞는가, 열면 **웹메일에서도 읽음**으로 바뀌는가
4. 외부 이미지가 든 광고 메일을 열면 "외부 이미지를 막았습니다"가 뜨고 [이미지 보기]로 보이는가
5. 첨부 메일의 [열기]·[저장], 링크 클릭
6. [계정 설정] → 삭제 후 다시 등록
7. 앱을 껐다 켜도 목록이 남아 있는가(이 PC 에 저장되므로 오프라인에서도 목록은 보여야 한다)

## 알려진 한계 (M1)
- 메일을 **받기만** 한다(보내기·답장은 M2). 화면의 **메일쓰기·내게쓰기·삭제·스팸신고·전달·이동** 버튼은 모양만 있고 아직 눌리지 않는다(M2·M3).
- 참고 화면에 있던 **청구서·쇼핑·소셜·프로모션 탭**은 만들지 않았다. 다음 메일이 서버에서 자동 분류하는 가상 분류라 IMAP 폴더로 보이는지 확인되지 않았다(실제 계정의 폴더 목록을 본 뒤 판단).
- 검색은 **제목·보낸 사람(이름·주소)** 만 찾는다(본문 검색은 M3). 이 PC 에 받아 둔 메일 안에서만 찾는다.
- 새 메일은 자동으로 가져오지 않는다(서버가 IDLE 미지원 → M3 에서 주기 확인 + 알림).
- 폴더별 안 읽은 수는 이 PC 에 받아 둔 최근 90일 기준이다.
- 본문은 처음 열 때 내려받으므로 그때는 인터넷 연결이 필요하다(한 번 연 메일은 오프라인에서도 열림).
- 한 번에 한 계정만 등록할 수 있다.
- 메일을 지우거나 폴더로 옮기는 기능은 없다(M3). 읽음·안 읽음 표시와 별표(중요)는 바꿀 수 있고 서버에도 반영된다.
