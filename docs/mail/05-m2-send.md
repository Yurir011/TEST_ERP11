## 만든 것
| 영역 | 내용 |
|---|---|
| **메일쓰기 / 내게쓰기** | 왼쪽 위 [메일쓰기]는 빈 쓰기 화면, [내게쓰기]는 받는 사람이 내 주소로 채워진 화면. 쓰기 화면은 같은 메일 창 안에서 열린다 |
| **답장 / 전체답장 / 전달** | 메일 읽기 화면의 버튼. 답장은 보낸 사람(Reply-To 가 있으면 그쪽)에게, 전체답장은 받는 사람·참조에서 **내 주소와 중복을 뺀** 나머지를 참조에 채운다. 제목은 `Re: `/`Fwd: `(이미 붙어 있으면 다시 붙이지 않음), 본문에는 원본을 인용(`> `)하거나 전달 머리글과 함께 넣는다. 전달은 **원본 첨부 파일이 함께 붙는다**. 답장에는 **대화 이어 붙이기**(In-Reply-To·References)가 실린다 |
| **쓰기 화면** | 보내는 사람(내 이름 + 내 메일 주소, 고정), 받는사람, [참조]·[숨은참조] 추가, 제목, [파일 첨부](파일 선택 창), 첨부 목록(× 로 빼기, 합계 크기 표시, 최대 20MB), 본문. [보내기] 또는 Ctrl+Enter. 보내는 중에는 버튼이 잠겨 **여러 번 눌러도 한 번만** 보낸다 |
| **보내기** | 직원 **본인 메일 계정**으로 SMTP(465/SSL)에 접속해 발송. 보내면 "메일을 보냈습니다" 안내와 함께 목록으로 돌아온다. 실패하면 이유를 쉬운 말로 보여 주고 **쓰던 내용·첨부는 그대로** 남아 다시 보낼 수 있다 |
| **쓰다 만 메일** | 내용이 있는데 [취소]를 누르거나 다른 폴더·메일로 이동하려 하면 "작성 중인 메일을 버릴까요?"를 묻고, 버리면 준비해 둔 첨부도 정리한다 |
| **보낸메일함 저장 설정** | 계정 설정 > [서버 설정 보기] 맨 아래 "보낸 메일을 보낸메일함에도 직접 저장"(기본 **꺼짐**). 서버가 SMTP 로 보낸 메일을 자동 저장하지 않을 때만 켠다. 켜면 보낸 원문을 IMAP 으로 보낸메일함에 저장(읽음 표시로). 보낸메일함 폴더를 못 찾으면 "보냈지만 저장하지 못했다"고 알린다 |

## 보안 장치
- **받는 사람 검사**: 줄바꿈·탭·널 같은 제어 문자가 든 주소는 거절(헤더 끼워 넣기 방지), 주소 형식 검사(한글 도메인 허용), 받는 사람 합계 50명, 같은 주소 중복 제거(받는 사람 > 참조 > 숨은참조 순으로 우선).
- **제목·보내는 사람 이름**은 줄바꿈을 공백으로 합쳐 한 줄로 만든다. 제목에 `\r\nBcc: ...` 를 넣어도 새 머리글이 생기지 않는다.
- **숨은참조(Bcc)** 는 발송 봉투에만 있고 메일 원문(머리글·본문) 어디에도 없다.
- **첨부 파일은 화면이 경로를 넘기지 않는다.** 파일 선택 창은 앱이 띄우고, 화면에는 앱이 준비한 첨부의 번호·이름·크기만 준다. 화면이 돌려보내는 것도 번호뿐이라 임의의 파일을 읽어 보낼 수 없다(없는 번호·경로 모양 번호는 거절). **사용자가 고른 원본 파일은 절대 지우지 않고**, 앱이 임시로 만든 전달용 사본만 보낸 뒤 또는 버릴 때 지운다(앱을 다시 켜면 남은 임시 파일도 정리).
- **한도**: 첨부 합계 20MB·20개, 제목 255자, 본문 1,000,000자. 서버 한도(약 70MB)보다 낮게 잡았다.
- **TLS 인증서 검증을 켠 채로** SMTP 에 접속(예외 코드 없음). 믿을 수 없는 인증서면 연결을 막는다.
- 오류 문구에는 서버 응답 원문·비밀번호를 싣지 않는다(응답 코드 숫자만).
- IPC: 서버 화면에서 온 요청만 받고(안내 화면·PDF 새 창은 거절), 요청 형식(문자열 길이·배열 크기)을 먼저 검사한다.

## 미확인 (직접 확인 필요)
1. **실제 다음스마트워크로 메일이 가는지**: 서버 로그인(SMTP 인증), 받는 사람에게 도착, 스팸함으로 가지 않는지, **보낸 사람 표시 이름**이 맞게 보이는지. (M1 에서 확인한 계정으로 [내게쓰기] → 보내기 → 받은메일함에 오는지 확인하는 것이 가장 쉽다.)
2. **서버가 보낸 메일을 자동으로 보낸메일함에 저장하는지**: 저장한다면 계정 설정의 "직접 저장"은 **꺼 둔 채** 쓰고, 저장하지 않아 보낸메일함이 비어 있다면 그 설정을 켜야 한다. 켠 채로 서버도 저장하면 같은 메일이 두 통 생긴다.
3. 발송 한도(분당·일일), 서버가 거절할 수 있는 첨부 형식(실행 파일 등).
4. **파일 선택 창**(Windows 대화상자)과 큰 첨부(20MB 근처)의 동작 — 자동 시험은 대화상자를 띄우지 않아 첨부 번호 흐름만 확인했다.
5. 받는 사람이 받은 메일에서 한글 제목·본문·첨부 이름이 깨지지 않는지(다른 메일 프로그램에서 열어 보기).

## 직접 확인 목록
1. 메일 창 → [내게쓰기] → 제목·본문 입력 → [보내기] → "메일을 보냈습니다" → 받은메일함에서 [새로고침]으로 도착한 메일 확인
2. 받은 메일에서 [답장] → 제목 `Re:`, 인용 본문 확인 → 보내기. 상대 메일 프로그램에서 대화로 이어져 보이는가
3. 첨부 메일에서 [전달] → 첨부가 붙어 있는가 → 다른 주소로 보내기
4. [파일 첨부]로 파일을 붙여 보내기, 첨부를 × 로 빼 보기
5. 잘못된 주소를 넣고 보내 안내 문구 확인, 내용을 쓴 뒤 [취소]·폴더 이동 시 확인창
6. **보낸메일함**에 보낸 메일이 보이는가(안 보이면 계정 설정의 "보낸 메일을 보낸메일함에도 직접 저장"을 켜고 다시 시험)

## 알려진 한계 (M2)
- 본문은 **텍스트만** 쓴다(굵게·색 같은 서식, 서명, HTML 메일 쓰기 없음).
- **임시보관(초안 저장)** 은 없다. 창을 닫으면 쓰던 내용은 사라진다(닫기 전 확인은 폴더·메일 이동과 [취소]에서만 한다).
- 주소록·자동 완성이 없다(M4 에서 거래처 연동 예정).
- 한 번에 한 통만 보낸다. 보낸 뒤에 취소할 수 없다.
- 문서(견적서 등)를 PDF 로 첨부해 바로 보내는 기능은 M4.
