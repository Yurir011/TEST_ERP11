# 메신저 탭(대화목록·즐겨찾기·전체목록)과 직원 상태

> 2026-10-17 · 승인: DB 표 추가(리비전 0009: `messenger_favorites`, `user_presence`) · 기존 표는 바꾸지 않음
> 참고: 요청에 말씀하신 주황색 화살표 그림은 첨부되지 않아, 글로 설명하신 위치(왼쪽 위 탭, 오른쪽 위 콤보박스)대로 만들었습니다. 배치가 다르면 알려 주세요.

## 화면
- **왼쪽 위 탭 3개**: `대화목록` · `즐겨찾기` · `전체목록`. 대화목록 탭에는 안 읽은 메시지 수, 즐겨찾기 탭에는 즐겨찾기한 사람 수가 붙는다.
  - **대화목록**: 기존 대화방 목록과 [새 대화].
  - **전체목록**: 모든 직원이 **이름 옆 체크박스**, 직급·직책, **현재 상태**(출근·외근·출장·휴가 등)와 함께 나온다. 체크하면 즐겨찾기에 들어가고, 풀면 빠진다. 이름 검색.
  - **즐겨찾기**: 체크한 직원만(상태와 함께). 즐겨찾기한 사람이 없으면 추가 방법을 안내한다.
  - 두 목록 모두 **이름을 누르면 그 직원과의 1:1 대화**가 열리고(없으면 만들고) 대화목록 탭으로 간다.
- **오른쪽 위 "내 상태" 콤보박스**: 출근 / 회의중 / 식사중 / 외근 / 출장 / 휴가 / 퇴근. 고르면 바로 저장되고 모두에게 실시간으로 보인다. 서버가 거절하면 이전 상태로 되돌리고 안내한다.

## 상태가 정해지는 규칙 (`services/presence.py`)
앞의 것이 우선이다.
1. **오늘 직접 고른 상태** 또는 **출근·퇴근 토글로 자동 설정된 상태**
2. 오늘이 **승인된 연차** 기간이면 `휴가` (출근 전이라도 자동)
3. 오늘 출퇴근 기록: 출근했으면 `출근`, 퇴근했으면 `퇴근`
4. 그 밖에는 `미출근`

- **출근 토글을 켜면 메신저 상태가 자동으로 `출근`**, 퇴근 토글을 누르면 `퇴근`이 된다(서버가 처리하므로 메신저 화면이 닫혀 있어도 적용되고, 열려 있는 모든 직원 화면에 실시간으로 반영).
- 직접 고른 상태는 **그날 하루만** 유지된다. 날짜가 지나면 저절로 무시되어 다음 날 아침에는 2~4 로 돌아간다(별도 초기화 작업 없음).
- 출근 후에 직접 고른 상태(외근 등)는 출근 상태를 덮고, 반대로 이미 `휴가`를 골라 둔 사람이 출근 토글을 켜면 `출근`이 된다.
- **콤보박스에서 `출근`·`퇴근`을 골라도 실제 출퇴근 기록은 바뀌지 않는다**(메신저 표시만 바뀐다). 근태 기록은 기존 출근 토글로만 남는다.
- 상태는 모든 직원에게 보이고 **본인만** 바꿀 수 있다. 변경 이력(감사 로그)에는 남기지 않는다.

## 즐겨찾기
- **본인만 보는 목록**이다(즐겨찾기당한 사람도, 다른 직원도 알 수 없다). 같은 사람의 다른 창에는 실시간으로 반영된다.
- 나 자신은 즐겨찾기할 수 없고(서버가 거절, DB 제약도 있음), 비활성 직원은 추가할 수 없다. 직원이 삭제되면 즐겨찾기도 함께 사라진다.

## API (`/api/messenger`, 로그인한 모든 직원)
| API | 내용 |
|---|---|
| `GET /directory` | 활성 직원(나 제외)의 현재 상태와 내가 즐겨찾기했는지. 직원 수와 상관없이 쿼리 고정 |
| `GET/PUT /status` | 내 현재 상태 / 내 상태 변경(출근·회의중·식사중·외근·출장·휴가·퇴근만 허용, `미출근`은 거절) |
| `PUT/DELETE /favorites/{user_id}` | 즐겨찾기 추가/해제(여러 번 불러도 같은 결과) |
| 실시간 | `presence.updated`(모든 접속자에게), `favorites.updated`(내 창에만) |

## 알아 둘 점
- 연차가 새로 **승인되는 순간**에는 실시간 알림을 보내지 않는다(상태는 화면을 열 때·다시 연결될 때·창을 다시 볼 때 계산해 갱신). 연차 승인 직후 다른 직원 화면에 `휴가`가 뜨기까지 그 시점의 새로고침이 필요할 수 있다.
- 상태는 메신저 화면이 열려 있는 동안에만 반영한다(다른 메뉴에서는 필요 없어 요청도 하지 않는다).

## 직접 확인 목록
`start.bat` 으로 서버를 켜고 앱(`npm.cmd run start:local`)과 브라우저에 서로 다른 직원으로 로그인해 메신저를 엽니다.
1. 왼쪽 위에 **대화목록 / 즐겨찾기 / 전체목록** 탭이 있는가
2. 전체목록에서 이름 옆 체크박스를 누르면 즐겨찾기 탭에 나타나고 풀면 사라지는가, 이름 옆에 현재 상태가 보이는가
3. 오른쪽 위 **내 상태** 콤보박스를 바꾸면 상대 화면의 내 이름 옆 상태가 바로 바뀌는가
4. **하루 처음 로그인해서 출근 토글을 켜면** 메신저 내 상태가 `출근`으로 바뀌는가(메신저가 열려 있지 않았다가 열어도 `출근`), 퇴근 토글은 `퇴근`
5. 승인된 연차가 오늘인 직원이 `휴가`로 보이는가
6. 이름을 누르면 1:1 대화가 열리는가
7. 내일 아침 다시 접속하면 직접 고른 상태(외근 등)가 사라지고 출근 전이면 `미출근`으로 돌아오는가
