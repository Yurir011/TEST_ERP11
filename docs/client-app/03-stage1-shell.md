# 1단계 — 데스크톱 앱 기본 틀

> 2026-10-17 · 코드: `desktop/`

## 실행

```
cd desktop
npm install
node node_modules/electron/install.js   # npm 이 설치 스크립트를 막는 PC 에서만 (Electron 실행 파일 받기)
npm.cmd start                           # 빌드 후 실행 (PowerShell 정책 때문에 npm.cmd)
npm.cmd run smoke                       # 창을 띄워 보안 설정만 확인하고 종료 (종료 코드 0 = 정상)
npm.cmd test                            # 단위 테스트
```

첫 실행에는 서버 주소를 묻는다(예: `http://192.168.0.10`). `/api/health`로 확인한 뒤 저장하고(`%APPDATA%\bench-desktop\config.json`), 그 서버의 화면을 불러온다.

## 만든 것

| 기능 | 내용 |
|---|---|
| 서버 화면 불러오기 | 설정한 서버 주소의 화면을 그대로 연다. 화면 코드는 바꾸지 않았다 |
| 안내 화면 | 첫 연결(서버 주소 입력), 서버에 연결 못할 때(다시 시도 / 주소 변경). NFC 리더 상태 표시 |
| 트레이 | 창을 닫으면 트레이로 내려간다. 메뉴: 열기, 서버 주소 변경, 종료. 한 번에 하나만 실행 |
| NFC | 시작할 때 리더를 찾아 연결하고 상태를 화면에 알린다. 카드 UID는 **서버 화면에만** 전달 (아직 로그인에는 쓰지 않음 — 3단계) |
| 알림·배지 | `benchClient.notify`, `setBadge` (메신저 단계에서 사용) |

## 보안 설정

- `contextIsolation`, `sandbox` 사용, `nodeIntegration` 끔. 화면에서 `require`/`process`가 보이지 않음을 smoke 로 확인.
- 화면에 노출한 기능은 `window.benchClient` 하나뿐(`src/preload.ts`).
- IPC 를 보낸 화면의 주소를 확인해 **설정한 서버 주소 또는 앱 안 안내 화면**만 받는다. 서버 주소 변경·재시도는 안내 화면에서만, 알림·배지·카드 UID 수신은 서버 화면에서만 가능.
- 서버 주소 밖으로의 이동은 막고, 외부 링크는 기본 브라우저로 연다.

## 직접 확인 목록

1. 서버(`start.bat`)를 켜고 `npm.cmd start` → 서버 주소 입력 → 로그인 화면이 뜨는가
2. 창 X 로 닫기 → 트레이에 남는가, 트레이 클릭으로 다시 열리는가, 트레이 > 종료로 끝나는가
3. 서버를 끈 채 실행 / 실행 중 서버를 끄고 새로고침 → "서버에 연결할 수 없습니다" 화면과 다시 시도
4. 안내 화면 아래 NFC 상태가 연결됨 → USB 뽑으면 바뀌고 → 꽂으면 몇 초 뒤 다시 연결됨
5. 앱을 두 번 실행 → 두 번째는 기존 창을 앞으로 가져오는가

## 팝업(새 창) 처리 — 2026-10-17

### 문제
처음 만든 앱은 새 창 요청을 모두 막고 `https` 주소만 외부 브라우저로 넘겼다. 화면이 PDF·이미지를 열 때 쓰는 `window.open(blob:…)`(`openFile`, 15곳)과 `mailto:`가 아무 반응 없이 사라졌다.

### 규칙 (`decideWindowOpen`, `main.ts`의 `hardenWindow`)
| 요청 | 처리 |
|---|---|
| 같은 서버의 페이지, 이 서버 화면이 만든 `blob:` (PDF·이미지 열기, 이미지 링크 `target=_blank`) | **앱 안의 새 창** (NFC·알림 기능 없음, 보안 설정 동일) |
| `mailto:`, `tel:` | 기본 메일·전화 프로그램 |
| 다른 사이트의 `http(s)` (팝빌 보기·PDF, 링크 첨부) | 기본 브라우저 |
| `file:`, `javascript:`, `data:`, `about:`, 다른 사이트가 만든 `blob:` | 막음 |

새 창에서 또 새 창을 열어도 같은 규칙이 적용되고, 서버 주소 밖으로는 이동할 수 없다.

### 검증
- 단위 테스트: 규칙 표 14건 포함 전체 통과.
- smoke (실제 Electron 안에서 가짜 서버로 10건 통과): PDF blob 새 창 열림 / 새 창에 `benchClient` 없음 / PDF 보기 화면이 그려짐 / mailto·https 는 기본 프로그램으로 전달 / file:·javascript: 는 아무것도 열지 않음 / 파일 다운로드(blob + `a[download]`) 완료.
- 확인하지 못한 것: PDF 글자까지 정확히 보이는지, 실제 메일 프로그램이 열리는지, 팝빌 화면, 인쇄 — 직접 확인.

### 직접 확인 목록
1. 문서관리에서 견적서/거래명세서 PDF 열기 → 앱 안 새 창에 PDF 가 보이는가, 그 창에서 인쇄·저장이 되는가
2. 세금계산서 이미지 클릭 → 새 창에 이미지가 보이는가
3. 문서 "발송" → 기본 메일 프로그램이 열리는가
4. 팝빌 "보기"/"PDF" → 기본 브라우저에서 열리는가
5. PDF 다운로드 버튼 → 저장 위치를 묻고 파일이 저장되는가
