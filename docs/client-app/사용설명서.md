# BENCH ERP 데스크톱 앱 사용 설명서

> 버전 V.0.70.150 · Windows 기준 · 앱은 웹 ERP 와 같은 화면에 **카드 로그인, 메신저 알림, 트레이**를 더한 프로그램입니다. 앱 없이 브라우저로도 모든 업무 기능을 그대로 쓸 수 있습니다(카드 로그인만 앱에서 됩니다).

## 1. 직원용

### 설치
1. 관리자에게 받은 `BENCH-ERP_V.0.70.150_Setup.exe` 를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (사내에서 직접 만든 프로그램이라 아직 발급된 서명이 없어서 나오는 경고입니다.)
3. 설치 위치를 확인하고 설치합니다. 관리자 권한이 필요하지 않습니다. 바탕화면에 **BENCH ERP** 아이콘이 생깁니다.
4. 실행하면 서버(`www.epik.bio:3102`)에 자동으로 연결되어 로그인 화면이 나옵니다. 주소를 따로 입력하지 않아도 됩니다.

### 로그인
- **이메일 + 비밀번호**: 웹과 같습니다.
- **NFC 카드**: 리더에 카드를 대면 바로 로그인됩니다. 다음 두 가지가 모두 되어 있어야 합니다.
  1. 이 PC 를 관리자가 **승인**했을 것 (앱을 처음 실행하면 자동으로 승인 요청이 가고, 관리자가 승인하면 됩니다)
  2. 내 카드를 관리자가 **등록**했을 것
- 카드를 대도 반응이 없으면: 로그인 화면 아래 "카드로 로그인" 문구에서 리더 상태를 확인하세요. 아래 [문제 해결]을 참고합니다.
- 이미 로그인한 상태에서는 카드를 받지 않습니다. 다른 사람이 쓰려면 로그아웃한 뒤 카드를 댑니다.
- 카드 로그인은 8시간 유지됩니다(비밀번호 로그인은 12시간). 카드나 PC 가 사용 중지되면 바로 로그인이 풀립니다.

### 창과 트레이
- 창의 **X 를 누르면 종료되지 않고 트레이(작업 표시줄 오른쪽 아래, ^ 를 누르면 보이는 숨은 아이콘)로 내려갑니다.** 메시지 알림을 계속 받기 위해서입니다.
- 트레이의 파란 BENCH 아이콘을 **누르면 창이 열립니다.** 우클릭하면 메뉴가 나옵니다.
  - 맨 위에 현재 버전, **BENCH ERP 열기**, **서버 주소 변경**, **윈도우 시작 시 자동 실행**(체크), **종료**
- **완전히 끝내려면 트레이 우클릭 → 종료**를 누르세요.
- **윈도우 시작 시 자동 실행**은 기본으로 꺼져 있습니다. 체크하면 PC 를 켤 때 창 없이 트레이에만 조용히 시작합니다. 이 설정은 이 PC 에만 적용됩니다(체크를 풀면 Windows 설정 → 앱 → 시작 프로그램에서도 사라집니다).
- 같은 앱을 두 번 실행해도 하나만 열리고, 기존 창이 앞으로 나옵니다.

### 메신저
- 사이드바 **메신저**. 왼쪽 위 탭: **대화목록 / 즐겨찾기 / 전체목록**.
  - **전체목록**: 모든 직원의 이름과 현재 상태(출근·외근·출장·휴가 등). 이름 옆 **체크박스**를 누르면 **즐겨찾기**에 들어갑니다(나만 보이는 목록). 이름을 누르면 1:1 대화가 열립니다.
  - **즐겨찾기**: 체크한 직원만 모아 봅니다.
- 오른쪽 위 **내 상태**: 출근 / 회의중 / 식사중 / 외근 / 출장 / 휴가 / 퇴근. 고르면 모두에게 바로 보입니다. 직접 고른 상태는 **그날 하루만** 유지됩니다.
  - **출근 토글(화면 오른쪽 위)을 켜면 상태가 자동으로 '출근'** 이 됩니다. 승인된 연차가 오늘이면 출근 전에도 '휴가'로 보입니다.
  - 콤보박스에서 '출근'·'퇴근'을 골라도 실제 출퇴근 기록은 바뀌지 않습니다. 근태는 출근 토글로만 남습니다.
- 메시지 입력: **Enter 로 보내기, Shift+Enter 로 줄바꿈**. 클립 버튼으로 파일(20MB까지)을 보냅니다. 그룹 대화는 [새 대화]에서 두 명 이상을 고르고, 참여자 추가·나가기·알림 끄기는 대화 화면 위쪽 버튼입니다.
- 메시지 옆의 **작은 숫자는 아직 읽지 않은 사람 수**입니다. 모두 읽으면 사라집니다.
- **새 메시지 알림**: 보고 있지 않은 대화의 메시지가 오면 알림이 뜨고, 작업 표시줄 아이콘에 안 읽은 수 배지가 붙고 깜박입니다. **알림을 누르면 그 대화로 바로 이동합니다.**

### 메일 (앱에서만)
- 사이드바의 **[메일] 버튼**(앱에서만 보입니다)을 누르면 **별도 창**으로 열립니다. 이미 열려 있으면 그 창이 앞으로 나옵니다. 창을 닫아도 ERP 는 그대로입니다.
- **처음 한 번 계정 등록**: 회사 메일 주소와 메일 비밀번호를 입력하고 [등록]을 누르면 접속을 확인한 뒤 저장합니다. 눈 모양 버튼으로 입력한 비밀번호를 확인할 수 있습니다.
  - 2단계 인증을 쓰는 계정은 일반 비밀번호 대신 **앱 비밀번호**를 입력하세요. 다음스마트워크에서 외부 프로그램(IMAP/SMTP) 사용이 꺼져 있으면 로그인이 되지 않으니 관리자에게 설정을 요청하세요.
  - 서버 주소는 기본값(다음스마트워크)이 들어 있습니다. 바꿀 일이 있으면 [서버 설정 보기]를 누르세요.
- **비밀번호는 이 PC 에서만 암호화해 보관**하고 ERP 서버로는 보내지 않습니다. 받은 메일도 이 PC 에만 저장됩니다.
- **화면**: 왼쪽에 내 이름과 폴더(전체메일·받은메일함·보낸메일함…), 오른쪽에 메일 목록입니다.
  - 왼쪽 위 **안읽음·중요·첨부**를 누르면 그 조건의 메일만 모아 봅니다(다시 누르면 풉니다).
  - 목록의 **별 모양**은 중요 표시입니다(웹메일에도 반영). 체크한 메일은 **읽음 표시**로 읽음/안 읽음을 바꿀 수 있습니다.
  - 위쪽 **검색**은 제목·보낸 사람을 찾습니다. **새로고침**으로 새 메일을 가져옵니다(최근 90일 메일). 아래 쪽 번호와 **보기 설정**(20/50/100개씩)으로 넘겨 봅니다.
  - 메일을 누르면 내용이 열리고(읽음으로 바뀌고 웹메일에도 반영) **목록** 버튼으로 돌아옵니다.
- **외부 이미지는 기본으로 막혀 있습니다**(보낸 사람이 열람 여부를 알아내는 것을 막기 위함). 믿을 수 있는 메일이면 [이미지 보기]를 누르세요.
- 첨부 파일은 **열기** 또는 **저장**. 프로그램을 실행하는 파일(`.exe`, `.bat` 등)은 한 번 더 확인합니다. 출처를 모르면 열지 마세요.
- **메일 쓰기**: 왼쪽 위 **메일쓰기**(빈 메일) 또는 **내게쓰기**(나에게 보내기). 받는 사람은 쉼표(,)로 여러 명 쓸 수 있고, **참조·숨은참조**는 오른쪽 글자를 눌러 추가합니다. **파일 첨부**로 파일을 붙입니다(합계 20MB까지). **보내기**(또는 Ctrl+Enter)를 누르면 **내 메일 계정으로** 발송됩니다.
  - 받은 메일을 열면 **답장 · 전체답장 · 전달** 버튼이 있습니다. 전달은 원본 첨부 파일도 함께 붙습니다.
  - 쓰던 내용이 있을 때 취소하거나 다른 폴더·메일로 이동하려 하면 버릴지 묻습니다. 저장해 두는 기능(임시보관)은 아직 없습니다.
  - 보낸 메일이 **보낸메일함에 보이지 않으면** 계정 설정(톱니 모양) > [서버 설정 보기]에서 "보낸 메일을 보낸메일함에도 직접 저장"을 켜 보세요. 이미 보이는데 켜면 같은 메일이 두 통 생기니 켜지 마세요.
- 아직 안 되는 것: 삭제·스팸신고·이동·임시보관, 본문 서식(글자 굵게 등), 서명.

### 새 버전이 나왔을 때
1. 화면 위쪽에 **"새 버전 V.0.70.151 이 있습니다 [다운로드]"** 안내가 뜹니다. (바쁘면 ×를 눌러 나중에 — 이번 실행 동안은 다시 묻지 않습니다.)
2. **[다운로드]**를 누르면 설치 파일이 내려받아집니다.
3. 트레이 우클릭 → **종료**로 앱을 끈 뒤, 내려받은 설치 파일을 실행합니다. 이전 설정(서버 주소, PC 승인 정보)은 그대로 유지됩니다.

| PDF 가 안 열린다 | 새 창으로 열립니다. 창 뒤에 숨어 있지 않은지 확인하세요 |

## 2. 관리자용

### 처음 한 번: PC 승인과 카드 등록 (대표 계정)
1. 직원이 앱을 처음 실행하면 **설정(직원등록) → 기기 관리**에 "승인 대기"로 나타납니다. PC 이름과 키 앞 8자리를 확인하고 **승인**합니다. (모르는 PC 의 요청은 **거절**)
2. **설정 → 직원 선택 → 수정 화면 아래 "NFC 카드"**: 앱에서 열고 **카드 읽기** → 리더에 카드를 대면 끝 4자리가 보입니다 → 카드 이름을 붙여 **카드 등록**. (브라우저에서는 카드 번호를 직접 입력)
3. 카드 분실·퇴사 시: 같은 화면에서 **사용 중지**(이미 로그인한 상태도 바로 풀림). 다른 직원에게 다시 쓰려면 **삭제**.
- 카드 한 장은 한 직원에게만 등록되고, 직원당 5장까지입니다. 기기 승인·중지는 **대표만** 할 수 있습니다.

### 새 버전 배포 (개발·관리 PC)
```
cd desktop
npm run dist                                   # 설치 파일 만들기 → desktop\release\BENCH-ERP_Setup_0.70.151.exe
npm run publish-release -- --notes "바뀐 내용"  # 서버에 올리기 → 직원 앱에 새 버전 안내가 뜬다
```
- 버전 번호를 올리는 방법과 규칙은 [`docs/version-policy.md`](../version-policy.md).
- 설치 파일에 들어가는 서버 주소는 `desktop/package.json` 의 `benchDefaultServer`(현재 `http://www.epik.bio:3102`). 다른 서버용은 `set BENCH_DEFAULT_SERVER=http://주소 && npm run dist`.
- 서버(Docker)가 다른 위치에 설치되어 있다면 `npm run publish-release -- --dir <서버의 storage\client_releases 경로>`.
- PowerShell 에서 실행하세요(한글 설명 `--notes` 가 정상 전달됩니다).

### 서버를 새 버전으로 올릴 때 (운영)
1. **DB 백업**(`pg_dump`) — README "백업과 복원".
2. 새 코드 배포 후 `alembic upgrade head`(이 버전에는 리비전 0007~0009 가 있습니다). `cryptography` 패키지가 추가되어 Docker 이미지를 다시 빌드해야 합니다.
3. Nginx 에 `/api/ws` 의 WebSocket 설정이 있어야 메신저 실시간 알림이 됩니다([06-stage4-messenger-server.md](./06-stage4-messenger-server.md) 참고).
4. **https 적용을 권장합니다.** 지금은 http 라서 로그인 토큰이 암호화되지 않고 오갑니다.

### 서명이 없는 설치 파일
Windows 코드 서명 인증서가 없어 직원 PC 에서 "PC 보호" 경고가 나옵니다(추가 정보 → 실행). 경고를 없애려면 코드 서명 인증서(유료)를 구입해 설치 파일에 서명해야 합니다. 사내 5명 규모에서는 안내만으로 충분하다고 판단해 아직 적용하지 않았습니다.
