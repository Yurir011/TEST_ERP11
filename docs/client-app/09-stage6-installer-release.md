## 미확인 (직접 확인 필요)
- **실제 시스템 알림을 눌렀을 때** 해당 대화로 이동하는지(앱→화면 신호와 화면의 이동은 각각 테스트로 확인, 시스템 알림 클릭은 사람이 눌러야 함)
- 작업 표시줄 **배지가 눈으로 어떻게 보이는지**(이미지는 만들어 포함했고 코드는 동작, 모양은 미확인)
- **윈도우 시작 시 자동 실행**: 켠 뒤 PC 를 다시 시작했을 때 트레이로만 시작하는지
- 새 버전 **안내 배너의 실제 모양**과, **이전 버전 위에 새 설치 파일을 덮어 설치**하는 동작(설치·삭제는 확인, 덮어쓰기 업그레이드는 시험하지 않음)
- **서명이 없어 나오는 Windows 경고** 화면(사용 설명서에 안내 문구가 있음)
- 운영 서버(Docker, Nginx, https)에서의 동작

## 직접 확인 목록
1. 설치 파일을 받아 설치 → 서버 주소 입력 없이 로그인 화면이 뜨는가(사용 설명서 [설치])
2. 트레이 우클릭 메뉴 맨 위에 `BENCH ERP V.0.70.150` 이 보이는가, 사이드바 아래에 `V.0.70.150` 이 보이는가
3. 트레이 메뉴의 **윈도우 시작 시 자동 실행**을 체크 → PC 를 다시 시작하면 창 없이 트레이로만 시작되는가 (체크를 풀면 시작 프로그램에서 사라지는가)
4. 다른 직원이 메시지를 보냈을 때 시스템 알림 → 알림을 누르면 앱이 앞으로 나오며 **그 대화방이 열리는가**, 작업 표시줄 아이콘이 깜박이고 안 읽은 수 배지가 붙는가
5. 새 버전 시험: 버전을 올려(`bump-version`) 설치 파일을 만들고 `publish-release` 한 뒤, 이전 버전 앱에서 **안내 → 다운로드 → 앱 종료 → 설치**가 되는가 (이전 설정이 유지되는가)
