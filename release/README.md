# release 폴더 — 직원에게 내려줄 설치 파일

이 폴더에 데스크톱 앱 설치 파일을 넣어 두면, **로그인 화면과 사이드바 맨 아래의 "데스크톱 앱 설치 파일 받기" 링크**로 직원이 로그인 없이 내려받을 수 있습니다.

## 넣는 방법
1. `desktop` 폴더에서 `npm run dist` 로 설치 파일을 만듭니다 → `desktop\release\BENCH-ERP_Setup_0.70.171.exe`
2. 그 파일을 이 `release` 폴더(프로젝트 루트의 `release`)에 **복사**합니다. (`desktop\release` 폴더에 그대로 두어도 인식됩니다.)
3. 서버를 다시 시작할 필요는 없습니다. 화면을 새로고침하면 링크가 나타납니다.

## 규칙
- 파일 이름은 `BENCH-ERP_Setup_<버전>.exe` 형식이어야 합니다(예: `BENCH-ERP_Setup_0.70.171.exe`). 다른 이름의 파일은 무시됩니다.
- 여러 버전이 들어 있으면 **가장 높은 버전**이 내려갑니다. 이전 버전 파일은 지우지 않아도 됩니다.
- 이 폴더의 파일은 git 에 올라가지 않습니다(이 안내 문서만 올라갑니다).
- 폴더 위치를 바꾸려면 `backend/.env` 에 `CLIENT_PUBLIC_RELEASE_DIRS=폴더경로` (여러 개는 `;` 로 구분)를 적습니다.

## 주의
- 이 링크는 **로그인 없이** 열립니다. 설치 파일에는 비밀번호나 키가 들어 있지 않고 서버 주소만 들어 있습니다.
- 이미 앱 안에서 화면을 보고 있는 직원에게는 링크가 보이지 않습니다.
- 앱 안의 "새 버전 안내"(`npm run publish-release`)는 이 폴더와 별개로 동작합니다.
